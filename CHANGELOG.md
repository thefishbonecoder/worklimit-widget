# Changelog

All notable changes to WorkMeter will be documented in this file.

## [1.0.0] - 2026-10-03

### Added

- Initial public Chromium release.
- Display of short-window and weekly ChatGPT usage limits.
- Reset countdowns and local reset times.
- Optional usage notifications at 25%, 10% and 0% remaining.
- Toolbar badge for remaining short-window usage.
- Current browser-session usage tracking.
- Local-only extension storage for normalized usage data and settings.
- Privacy policy and MIT license.
